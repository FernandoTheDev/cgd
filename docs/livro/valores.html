O livro do CGD

Valores, tipos e variáveis

Variáveis guardam valores que podem mudar; constantes travam o nome naquele valor inicial. Você pode anotar o tipo explicitamente com dois-pontos ou deixar o compilador inferir para você.

var, const e inferência

Use var quando o valor vai mudar ao longo do programa, e const quando quiser garantir que aquele nome não seja reatribuído. Para deixar o contrato bem claro (especialmente em bibliotecas e funções), anote o tipo logo após o nome com dois-pontos.

var contador: inteiro = 0
var titulo = "CGD"
const limite: inteiro = 10

Tipos disponíveis e valores iniciais padrão

Se você declarar uma variável tipada sem valor inicial, tipos primitivos e coleções já nascem prontos para uso — já objetos, funções e tuplas começam como nulo para não rodar código escondido.

RecursoComo funciona
numero / númeroAceita inteiro e real; começa em 0.
inteiro / longoInteiro de 64 bits com sinal. Se estourar o limite (overflow), lança erro tratável.
real / decimalNúmero decimal de ponto flutuante (64 bits); começa em 0.0.
logico / booleano / binarioverdadeiro ou falso; começa em falso.
textoTexto UTF-8 imutável; começa vazio (""). Índices contam caracteres Unicode.
T[]Vetor tipado (ex.: inteiro[], texto[]); começa como um vetor vazio novo.
dicionario / dicionárioMapa de chave e valor; começa como um dicionário vazio novo.
Promessa e TarefaTipos nativos do CGD para funções assincrona e rotinas paralelas.
qualquer, classe, interface, funcao, tuplaComeçam como nulo quando declarados sem valor inicial.

// Declaração, valores primitivos e tipo de em execução.
var vazio: qualquer
const ativo: logico = verdadeiro
var idade: inteiro = 20
var medida: real = 2.5
escreva(vazio, ativo)
escreva(tipo de idade, " ", tipo de medida, " ", tipo de "olá", " ", tipo de ativo)
