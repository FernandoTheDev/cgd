O livro do CGD

Biblioteca nativa e entrada/saída

Você não precisa começar tudo do zero. Estas funções já estão disponíveis para escrever na tela, ler uma entrada, converter valores e trabalhar com coleções.

Entrada e saída básicas

escreva formata valores e termina a linha; leia lê uma linha da entrada padrão, com mensagem opcional. texto, inteiro, real e numero são conversões explícitas e podem falhar. Para arquivos e HTTP, use as classes de biblioteca documentadas, não uma função global inventada.

var entrada: texto = leia("Idade: ")
tente { escreva(inteiro(entrada)) } pegue { escreva("inteiro inválido") }

Operações gerais

tamanho consulta coleções/texto; clonar copia dados; mapear, filtrar, paraCada, todosEmCondicao e ordenar recebem callbacks sem captura. aleatorio produz real em [0, 1); aleatorioEntre usa limite superior exclusivo. decoradores devolve cópia dos metadados. tipo de é uma expressão para consultar a categoria do valor. Métodos nativos são sugeridos pelo tipo do receptor, nunca por uma lista global após ponto.

Experimente: 21_biblioteca

escreva(inteiro("12"), real(".5"), 1234.5689.formatar())
funcao par(x: qualquer): qualquer {
    retorna x % 2 == 0
}

escreva(filtrar([1, 2, 3, 4], par), todosEmCondicao([2, 4], par))
paraCada([1, 2], funcao(x: qualquer): qualquer {
    escreva(x * 2)
})
