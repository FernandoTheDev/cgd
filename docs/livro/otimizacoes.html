O livro do CGD

Otimização (-o) e CTFE (@puro)

Passar -o ativa otimizações do compilador e -O2 no Clang/GCC. Regra de ouro do CGD: otimizar nunca pode mudar o comportamento observável, apagar efeitos ou esconder exceções.

Calculando resultados na compilação com @puro

Coloque o decorador @puro acima de uma função livre ou de um método estático que só depende dos próprios parâmetros. Com -o, quando ela for chamada com valores constantes, a VM interna do CGD calcula o resultado durante a compilação e substitui direto no código C gerado. A sintaxe antiga //>puro segue aceita por compatibilidade, mas @puro é a forma recomendada.

@puro
funcao fatorial(n: inteiro): inteiro {
    se n <= 1 { retorna 1 }
    retorna n * fatorial(n - 1)
}
const resultado: inteiro = fatorial(6) // já vira 720 com -o

O que o otimizador simplifica com segurança

O gerenciador de passes roda até atingir ponto fixo: dobra operações constantes (aritmética, unários, comparações, textos), propaga constantes tipadas com segurança, simplifica curto-circuito (verdadeiro e x, falso ou x) e remove caudas comprovadamente inalcançáveis — preservando blocos finalmente e efeitos colaterais.

Experimente: 26_ctfe

// A VM é usada na compilação, não na execução do binário final.
//>puro
funcao fibonacci(n: inteiro): inteiro {
    se n < 2 {
        retorna n
    }

    retorna fibonacci(n - 1) + fibonacci(n - 2)
}

escreva(fibonacci(10))

Experimente: 09_ctfe_fluxo_escopos

// A VM preserva senão, slots locais, parâmetros mutáveis e ordem de argumentos.
//>puro
funcao escolher(condicao: qualquer): qualquer {
    se condicao {
        retorna 1
    } senao {
        retorna 2
    }
}

//>puro
funcao combinar(a: qualquer, b: qualquer): qualquer {
    retorna a * 10 + b
}

//>puro
funcao calcular(): qualquer {
    var valor: numero = 1
    se verdadeiro {
        var valor: numero = 99
    }

    retorna combinar(valor++, valor++)
}

escreva(escolher(falso), calcular())
