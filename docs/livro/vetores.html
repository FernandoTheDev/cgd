Vetores, compreensão e fatias

Vetores guardam uma sequência que pode mudar. Você pode acessar posições, percorrer os elementos, escolher uma fatia ou construir outro vetor com uma compreensão.

Literais, spread e compreensão

Use [a, b] para vetor; ... espalha elementos. Compreensão filtra e transforma em um novo vetor, sem mudar a coleção original. O vínculo de iteração pode ter anotação.

var original: inteiro[] = [1, 2, 3]
var copia: inteiro[] = [...original, 4]
var pares = [x*2 para cada x: inteiro em original se x > 1]

Fatias e métodos

v[inicio:fim:passo] usa fim exclusivo. Início/fim podem ser omitidos, passo pode ser negativo e zero é inválido. Métodos incluem adicionar/empilhar, remover, removerPrimeiro/removerUltimo, inverter, somar, juntar, concatenar, encaixar, ordenar, mapear e filtrarPor. As operações que mutam atuam sobre aliases da mesma coleção; fatiar e concatenar produzem resultados próprios. Callbacks são funções sem captura.

Experimente: 09_vetores

var valores: qualquer[] = [3, 1, 2]
valores.ordenar()
escreva(valores, valores.somar())
var removidos: qualquer = valores.encaixar(1, 1, 7, 8)
escreva(removidos, valores)

Experimente: 30_metodos_vetor

var v: qualquer[] = [1, 2]
v.empilhar(3)
escreva(v.concatenar([4]).ordenar(funcao(a: qualquer, b: qualquer): qualquer {
    retorna b - a
}))
v.adicionar(4)
escreva(v.removerPrimeiro(), v.removerUltimo())
escreva(v.removerUltimo())
escreva(v.removerPrimeiro())
escreva([1, 2, 3].filtrarPor(funcao(x: qualquer): qualquer {
    retorna x < 3
}).mapear(funcao(x: qualquer): qualquer {
    retorna x * 3
}))

Métodos: adicionar, empilhar, tamanho, inclui/contem/contém, fatiar, mapear, filtrarPor, remover, removerPrimeiro, removerUltimo, inverter, somar, juntar, concatenar, encaixar e ordenar. Restrições por aliases são monotônicas; modificar durante a iteração não cria snapshot. filtrar global recebe vetor e função; não existe método reduzir neste perfil.
