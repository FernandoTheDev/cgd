Vetores, compreensão e fatias

Vetores guardam listas ordenadas de valores. Você pode tipar o vetor (inteiro[]), recortar fatias com passo (valores[::-1]), espalhar elementos (...lista) e criar listas filtradas em uma linha.

Literais, espalhamento (...) e compreensão

Use colchetes [1, 2, 3] para criar um vetor e ... para espalhar elementos dentro de outro vetor. Compreensões criam um vetor novo filtrando e transformando sem alterar o original.

var base: inteiro[] = [1, 2, 3]
var maior: inteiro[] = [...base, 4]
var pares = [x * 2 para cada x: inteiro em maior se x % 2 == 0]

Fatias com [inicio:fim:passo]

O fim da fatia é exclusivo. Você pode omitir início ou fim, e usar passo negativo para inverter rapidamente (valores[::-1]). Passo zero é bloqueado já na compilação (E3108).

Experimente: 09_vetores

var valores: qualquer[] = [3, 1, 2]
valores.ordenar()
escreva(valores, valores.somar())
var removidos: qualquer = valores.encaixar(1, 1, 7, 8)
escreva(removidos, valores)

Experimente: 10_compreensao_fatias

var valores: qualquer[] = [1, 2, 3, 4, 5]
escreva([x * 3 para cada x: inteiro em valores se x % 2 == 0])
escreva(valores[::-1], valores[::2])

Experimente: 22_contratos_aliases

var numeros: inteiro[] = [1]
var alias: qualquer = numeros
tente {
    alias.adicionar("texto")
}
pegue {
    escreva("bloqueado")
}

escreva(numeros)

Experimente: 30_metodos_vetor

var v: qualquer[] = [1, 2]
v.empilhar(3)
escreva(v.concatenar([4]).ordenar(funcao(a: qualquer, b: qualquer): qualquer {
    retorna b - a
}))
v.adicionar(4)
escreva(v.removerPrimeiro(), v.removerUltimo())
escreva(v.removerUltimo())
escreva(v.removerPrimeiro())
escreva([1, 2, 3].filtrarPor(funcao(x: qualquer): qualquer {
    retorna x < 3
}).mapear(funcao(x: qualquer): qualquer {
    retorna x * 3
}))

Ver exemplo completo e contrato de teste no GitHub

Métodos de vetor: adicionar, empilhar, tamanho, inclui/contem/contém, fatiar, mapear, filtrarPor, remover, removerPrimeiro, removerUltimo, inverter, somar, juntar, concatenar, encaixar e ordenar. Em vetores tipados (ex.: inteiro[]), o compilador já rejeita inserções de tipo errado estaticamente.
