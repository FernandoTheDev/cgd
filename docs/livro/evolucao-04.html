O livro do CGD

Interfaces, classes abstratas, enums e FFI C

Quando o projeto cresce, interfaces ajudam a firmar contratos claros entre classes, enums organizam constantes numéricas e @definicao permite ligar funções C direto no executável.

Interfaces e classes abstratas

Uma interface descreve os campos e métodos públicos que uma classe promete entregar usando implementa. Uma classe abstrata não pode ser instanciada diretamente e pode definir métodos abstrato para as filhas completarem.

interface Nomeavel {
    nome(): texto;
}
classe Pessoa implementa Nomeavel {
    nome(): texto { retorna "Ana" }
}

Enums numéricos em qualquer escopo

Você pode declarar enum no módulo, dentro de funções, blocos ou classes. Os valores incrementam automaticamente a partir de 0 (ou do número que você definir), são imutáveis e funcionam inclusive dentro de funções //>puro (CTFE).

enum Estado { Inicio, Rodando, Final = 7 }
var atual: Estado = Estado.Final

FFI C com @definicao e classe estrangeira

Precisa chamar uma função C de uma biblioteca do sistema (como libm)? Declare uma classe estrangeira com @definicao(biblioteca="m") e mapeie cada símbolo. Na ABI C escalar, numero/real viram double, inteiro/longo viram int64_t, logico vira bool e texto vira const char*.

Lembre-se: FFI é uma fronteira de confiança — confira sempre se os tipos declarados batem exatamente com a função C real.

Experimente: 38_contratos

interface Medida {
    valor(): inteiro;
}

classe abstrata Base {
    abstrato valor(): inteiro;
}

classe Concreta herda Base implementa Medida {
    valor(): inteiro {
        retorna 5
    }
}

enum Estado {
    Inicial, Final = 7
}

var objeto: Medida = Concreta()
var duplicar: funcao = (valor: inteiro): inteiro => valor * 2
escreva(objeto.valor())
escreva(Estado.Final)
escreva(duplicar(3))

Experimente: 40_enums_escopos

funcao estado(): inteiro {
    enum Estado {
        Inicio, Final = 7
    }

    var atual: Estado = Estado.Final
    retorna atual
}

classe Maquina {
    enum Estado {
        Inicio, Final = 4
    }

    atual: Estado = isto.Estado.Final
}

var vetor: funcao = (x: inteiro) => [x, x + 1]
escreva(estado())
escreva(Maquina.Estado.Final)
escreva(vetor(2))
