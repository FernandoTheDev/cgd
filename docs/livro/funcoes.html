O livro do CGD

Funções e parâmetros

Dê nome a uma operação para usá-la de novo. Depois, passe funções como argumentos e experimente valores padrão, argumentos variáveis e callbacks sem captura.

Parâmetros e retornos

Use funcao/função, argumentos tipados opcionais e retorno após dois-pontos. Parâmetros opcionais devem vir depois dos obrigatórios; o espalhamento deve ser o último. Um parâmetro padrão pode usar parâmetros anteriores. Sem retorna, o valor final é nulo, não a última expressão.

funcao somar(a: inteiro, b: inteiro = 1): inteiro {
    retorna a + b
}
var duplicar: funcao = (x: inteiro): inteiro => x * 2

Sem captura implícita

Funções e arrows podem ser valores e callbacks. Não carregam variáveis do ambiente externo: passe os dados por parâmetros. Capturas geram aviso e erro. Métodos ligados mantêm seu receptor explicitamente gerenciado. Esta decisão evita introduzir um ambiente de closures com semântica parcial.

Assincronismo experimental do CGD

assincrona funcao f(): T inicia imediatamente e devolve Promessa. aguardar suspende apenas o corpo assíncrono atual e retoma por uma microtask, inclusive para resultados prontos. O runtime drena essas continuações depois da raiz síncrona. Não há threads paralelas.

Funções e métodos assíncronos aceitam tente/pegue/finalmente, laços, escolha, compreensões e spread. Classes locais em corpos assíncronos recebem E3305. Promessa oferece combinadores e cancelamento cooperativo. O módulo cgd:assincrono fornece temporizadores, cliente HTTP e TCP sobre o reactor Linux. As bibliotecas Tempo, Rede e Processo mantêm suas operações síncronas. Os contratos e limites experimentais estão em docs/assincronismo.md.

Experimente: 07_funcoes

funcao soma(a: inteiro, b: inteiro = a + 2): inteiro {
    retorna a + b
}

funcao reunir(primeiro: qualquer, ... resto: qualquer): qualquer {
    retorna [primeiro, ... resto]
}

escreva(soma(3))
escreva(reunir(1, ...[2, 3]))

Experimente: 08_funcoes_valores

funcao dobro(x: qualquer): qualquer {
    retorna x * 2
}

var operacao: funcao = dobro
funcao criar(): qualquer {
    // Esta função não captura nenhuma variável de criar().
    retorna funcao(x: qualquer): qualquer {
        retorna x + 4
    }
}

escreva(operacao(3))
escreva(criar()(5))
escreva(mapear([1, 2, 3], funcao(x: qualquer): qualquer {
    retorna x * 3
}))

Experimente: 41_assincronismo

assincrona funcao maisUm(valor: inteiro): inteiro {
    retorna valor + 1
}

assincrona funcao mostrar(): vazio {
    escreva("início")
    const futuro: Promessa < inteiro > = maisUm(10)
    const resultado = aguardar futuro
    escreva(resultado)
}

escreva("raiz")
mostrar()
escreva("continua")
