O livro do CGD

JSON, rede, arquivos e coleções do CGD

Para ler arquivos, conversar por HTTP ou trabalhar com JSON, importe uma das bibliotecas cgd:. Cada módulo reúne classes voltadas para uma tarefa.

Escolher uma biblioteca

RecursoComo funciona
cgd:jsonJSON.deTexto, analisar/serializar, obter/contem/caminho/definir/copiar/chaves. Profundidade, nós, Unicode, números grandes e ciclos têm contratos explícitos.
cgd:redeSessao de libcurl; ClienteHTTP e RespostaHTTP com obter/enviar/enviarJSON/atualizar/remover. Rede só acontece quando o programa pede.
cgd:arquivosArquivo(caminho): ler/linhas/escrever/anexar/informacoes/tamanho/remover. Cada chamada fecha seu descritor; leitura padrão 16 MiB, teto 64 MiB.
cgd:matematicaMatematica sobre libm: seno/cosseno/tangente/raizQuadrada/potencia/absoluto/piso/teto/logaritmo/exponencial.
cgd:colecoesColecoes.unicos/intervalo/reduzir/agrupar/achatar. Callbacks não capturam ambiente.
cgd:nativoPrimitivas da ABI gerenciada para implementar bibliotecas; prefira as classes públicas acima nos programas.

I/O e respostas com erros

Arquivo preserva bytes, inclusive zero interno; operações Unicode ainda exigem UTF-8 válido. Escrita pode ser parcial se o sistema falhar: não é transação. ClienteHTTP usa sessão isolada por requisição; sucesso exige transporte sem erro e status 200..299. exigirSucesso transforma uma resposta inspecionável em exceção tratável. Nunca há rede automática no editor.

Experimente: json_classe

var biblioteca: qualquer = importar("../../bibliotecas/json.delegua")
var dados: qualquer = biblioteca.JSON.analisar('{"nome":"CGD","versao":1}')

escreva(biblioteca.JSON.serializar(dados))

var documento: qualquer = biblioteca.JSON(dados)
escreva(documento.obter("nome"))
escreva(documento.definir("versao", 2).texto())

Experimente: json_navegacao

var json: qualquer = importar("cgd:json")
var documento: qualquer = json.JSON.deTexto('{"pessoa":{"nome":"Ana"},"valor":null}')
escreva(documento.caminho(["pessoa", "nome"]))
escreva(documento.obter("ausente", 7))
escreva(documento.obter("valor", 7))
var copia: qualquer = documento.copiar()
copia.definir("novo", verdadeiro)
escreva(documento.contem("novo"))

JSON em Delégua puro, limite de profundidade e preservação de números além da representação nativa. Rede exige libcurl >=7.86; opções com ponteiros/callbacks arbitrários são recusadas. WebSocket depende da libcurl instalada, não validado neste ambiente. I/O usa arquivos regulares, fecha descritores por chamada e limita leituras/escritas a 64 MiB.
