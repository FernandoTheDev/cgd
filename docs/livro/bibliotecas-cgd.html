O livro do CGD

Bibliotecas cgd:* (Web, Dados, Cripto e Sistema)

O CGD vem com 24 módulos prontos instalados em ~/.delegua/cgd. Você importa apenas o que precisa com importar("cgd:nome") e o LSP já completa os nomes e métodos no VS Code.

Mapa completo dos 24 módulos em ~/.delegua/cgd

RecursoComo funciona
cgd:servidorServidor HTTP/1.1 com rotas, parâmetros, JSON, middlewares e modo concorrente epoll (escutarAsync + keep-alive).
cgd:redeCliente HTTP síncrono e assíncrono sobre libcurl (ClienteHTTP, RespostaHTTP, obter/enviar/enviarJSON).
cgd:socketsSockets TCP/UDP, resolução DNS e suporte a IPv6 (OuvinteTCP, Conexao, SocketUDP, resolverDNS).
cgd:assincronoTempo.dormir, HTTP e TCP assíncronos sobre epoll, Canal limitado e GrupoTarefas.
cgd:jsonParser e serializador JSON em Delégua puro com limites de profundidade e navegação por caminho.
cgd:sqliteBanco SQLite (libsqlite3) com consultas parametrizadas, transações e fechamento explícito.
cgd:bytesBuffer binário nativo (Bytes) para manipular bytes, hex, base64 e fatiamento sem depender de texto UTF-8.
cgd:criptoHashes SHA-256/SHA-512, HMAC e bytes aleatórios criptográficos sobre OpenSSL (libcrypto).
cgd:compressaoCompressão e descompressão gzip/deflate (zlib) com teto contra bombas de descompressão.
cgd:arquivosLeitura, escrita, linhas, JSON, cópia e remoção de arquivos regulares com limite seguro de memória.
cgd:processo / cgd:ambiente / cgd:sistemaExecução de subprocessos sem shell (argv separado + timeout), variáveis de ambiente e dados do sistema.
cgd:tempoRelógios, Duracao, Cronometro, dormirAsync e calendário DataHora.
cgd:io / cgd:cli / cgd:logEntrada/saída estruturada, parser de argumentos de linha de comando e logger estruturado.
cgd:textos / cgd:colecoes / cgd:caminhosUtilitários de string, transformações de vetores (agrupar, reduzir, particionar, blocos) e caminhos POSIX.
cgd:matematica / cgd:estatistica / cgd:algoritmosFunções matemáticas (libm), média/mediana/variância/desvio padrão, busca binária e CRC32.
cgd:nativoPrimitivas da ABI gerenciada usadas internamente para construir as bibliotecas acima.

Experimente: bytes_cripto_sqlite

const Bytes: qualquer = importar("cgd:bytes").Bytes
const Cripto: qualquer = importar("cgd:cripto").Cripto
const Comp: qualquer = importar("cgd:compressao").Compressao
const SQLite: qualquer = importar("cgd:sqlite").SQLite
const DataHora: qualquer = importar("cgd:tempo").DataHora

escreva(Bytes.deTexto("abc").paraHex())
escreva(Cripto.sha256("abc"))

const gz: texto = Comp.gzipComprimir("delegua-compilador-c99")
escreva(Comp.gzipDescomprimir(gz) == "delegua-compilador-c99")

const db: qualquer = SQLite.abrir(":memory:")
tente {
    db.executar("CREATE TABLE pessoas (id INTEGER PRIMARY KEY, nome TEXT)")
    db.executar("INSERT INTO pessoas (nome) VALUES (?)", ["Ana"])
    const linha: qualquer = db.consultarUm("SELECT nome FROM pessoas WHERE id = ?", [1])
    escreva(linha["nome"])
} finalmente {
    db.fechar()
}

escreva(DataHora.deUTC(2026, 11, 20, 14, 30, 5).formatarISO())

Experimente: http

// Servidor local: execute e acesse http://127.0.0.1:8080/.
// GET /parar encerra este exemplo; não exponha essa rota em aplicações públicas.
const Servidor: qualquer = importar("cgd:servidor")
var app: qualquer = Servidor.HTTP()
app.get("/", funcao(req: qualquer, res: qualquer): vazio {
    res.enviar("Olá, CGD!\n")
})
app.get("/usuarios/:nome", funcao(req: qualquer, res: qualquer): vazio {
    res.json({ nome: req.parametro("nome"), pagina: req.query("pagina", "1") })
})
app.post("/api/eco", funcao(req: qualquer, res: qualquer): vazio {
    res.status(201).json(req.json())
})
app.head("/", funcao(req: qualquer, res: qualquer): vazio {
    res.enviar("Olá, CGD!\n")
})
app.get("/parar", funcao(req: qualquer, res: qualquer): vazio {
    res.enviar("Até logo!\n").pararServidor()
})
app.escutar("127.0.0.1", 8080)
