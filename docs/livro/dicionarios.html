O livro do CGD

Dicionários, tuplas e clonagem

Use um dicionário para procurar um valor pela chave, e uma tupla para reunir valores sem mudar sua estrutura. Neste capítulo, você também verá como copiar coleções sem perder suas relações.

Chaves, pares e presença

Dicionários usam chaves nulas, lógicas, numéricas ou textuais. A chave 1 e a chave 1.0 identificam a mesma entrada; verdadeiro é uma chave diferente. Chaves numéricas não finitas são rejeitadas. A ordem de iteração não é ordem de inserção prometida.

var dados: dicionario = { nome: "Ana", ativo: nulo }
escreva(dados.obter("nome", "sem nome"))
escreva(dados.contemChave("ativo"))
para cada par: qualquer em dados { escreva(par[0], par[1]) }

Tuplas, desestruturação e cópia

Literais como (1, "a") criam tuplas imutáveis; tupla(vetor) converte coleções de 2 a 10 elementos. Propriedades ordinais como primeiro e segundo dão acesso aos membros. Desestruturação const { nome: texto } = dados cria um vínculo, sem copiar profundamente o objeto. clonar suporta ciclos e mantém identidades compartilhadas dentro da cópia; não clona código de função nem abre outro recurso nativo.

Experimente: 11_dicionarios

var original: dicionario = { a: 1 }

var dados: dicionario = { ... original, b: 2 }
// dados.obter("b")

const { a: qualquer, b: qualquer } = dados
escreva(a, b)

para cada { chave: texto, valor: inteiro } em { x: 7 } {
    escreva(chave, valor)
}

escreva("a" em dados)

Experimente: 12_tuplas

// Tuplas possuem acesso por índice e por propriedades ordinais.
var tuplaLiteral: tupla = [(1, "texto")]
var tipada: (numero, texto) = tupla([2, "outro"])
escreva(tuplaLiteral[0], tuplaLiteral.segundo)
escreva(tipada)

Experimente: 20_clonagem

var original: dicionario = { dados: [1] }

var copia: qualquer = clonar(original)
copia.dados.adicionar(2)
escreva(original.dados, copia.dados)
var ciclo: qualquer[] = []
ciclo.adicionar(ciclo)
var clonado: qualquer = clonar(ciclo)
escreva(clonado[0] == clonado)

Experimente: 37_dicionario_obter

var dados: dicionario = { "presente": nulo }
escreva(dados.obter("ausente", 42))
escreva(dados.obter("presente", 42))
escreva(dados.contemChave("presente"))
dados.definir("nome", "CGD")
var itens: qualquer[] = dados.itens()
dados.limpar()
escreva(tamanho(itens))
escreva(tamanho(dados))

Dicionários: chaves, valores, tamanho, remover e inclui/contem/contém. Tuplas: tamanho, inclui/contem/contém e fatiar, além das propriedades ordinais demonstradas. A iteração de dicionários não garante ordem de inserção. Dicionários também oferecem obter(chave, padrão), definir, contemChave, itens e limpar. Nulo armazenado não é ausência.
