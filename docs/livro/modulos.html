O livro do CGD

Módulos estáticos

Quando o programa crescer, divida o código em arquivos. A importação usa caminhos conhecidos na compilação e resolve cada caminho a partir do arquivo que o declara.

Importação literal e namespace

importar recebe um caminho literal .delegua relativo ao módulo importador, ou um alias de biblioteca cgd:. A unidade é carregada na compilação, inicializada uma vez na execução e acessada como namespace. Não são importados pacotes NPM, código baixado ou nomes computados.

var biblioteca: qualquer = importar("cgd:json")
var documento: qualquer = biblioteca.JSON.deTexto("{}")

Identidade, ciclos e visibilidade

O carregador canonicaliza caminhos, aplica orçamento e detecta ciclos com cadeia de importação. Arquivos abertos em memória prevalecem sobre disco no LSP. Tipos de classes possuem identidade de declaração; um nome igual em outro módulo não é o mesmo tipo. Herança por alias dinâmico de classe importada não é resolvida. A ausência de busca irrestrita no disco torna o trabalho do editor limitado e previsível.

Experimente: 01_importacao

var calculos: qualquer = importar("lib/calculos.delegua")
var outraReferencia: qualquer = importar("./lib/calculos.delegua")
escreva(calculos.soma(3), outraReferencia.versao, calculos.Valor(4).dado)

Inicialização é única; se falhar, permite nova tentativa. Exportações não podem ser substituídas. Importação dinâmica, NPM e código estrangeiro são excluídos.
