Com limites

Valores, tipos e variáveis

Use var para variáveis e const para vínculos constantes. As anotações aparecem após dois-pontos. Nulo, lógicos, números, textos, coleções, objetos e funções são valores gerenciados.

linguagem/01_tipos.delegua

Abrir fonte e contrato de teste 

// Declaração, valores primitivos e tipo de em execução.
var vazio
const ativo = verdadeiro
var idade: inteiro = 20
var medida: real = 2.5
escreva(vazio, ativo)
escreva(tipo de idade, " ", tipo de medida, " ", tipo de "olá", " ", tipo de ativo)
linguagem/03_atribuicoes.delegua

Abrir fonte e contrato de teste 

var a, b = 1, 2
a, b = b, a  // Os valores da direita são avaliados antes das escritas.
var contador = 2
contador += 5
escreva(a, b, contador)
var destino = 0
escreva(destino = 5)
linguagem/25_escopos.delegua

Abrir fonte e contrato de teste 

var x = 1
se verdadeiro { var x = 2; escreva(x) }
escreva(x)
funcao criar() {
    retorna auxiliar
    funcao auxiliar(x) { retorna x * 2 }
}
escreva(criar()(4))

Constante impede reatribuir o vínculo; coleções continuam tendo sua mutabilidade própria. Inteiros/longo têm 64 bits e reais/decimal usam ponto flutuante de 64 bits. Não há bigint.

Disponível

Operadores e ordem de avaliação

Aritmética, potência, divisão inteira, bits, comparações, pertencimento, atribuições compostas e incremento. Os argumentos e índices são avaliados na ordem da fonte.

linguagem/02_operadores.delegua

Abrir fonte e contrato de teste 

// Potência, divisão inteira, bits, comparação e curto-circuito.
escreva(2 ** 5, 100 \ 3, 5 & 3, 1 << 0)
escreva(3 != 4, falso e (1 / 0), nulo ?: 10)
linguagem/35_bits_e_atribuicoes.delegua

Abrir fonte e contrato de teste 

var n = 8
escreva(n | 1, n >> 3)
escreva(3 ^ 2, ~1, 5 & 3)
var a = 9
a -= 1
a *= 2
a /= 4
a %= 3
escreva(++a + 1)

e/ou retornam o valor selecionado. 0, texto vazio e coleções vazias são verdadeiros; falso e nulo são falsos. ?: troca somente nulo. Overflow e divisão por zero lançam exceção.

Disponível

Laços como expressões

Um laço usado como expressão constrói um vetor. retorna dentro do coletor contribui um valor ao resultado; o compilador distingue esse retorno do retorno da função.

linguagem/06_lacos_resultado.delegua

Abrir fonte e contrato de teste 

// Retornos dentro de uma expressão de laço acumulam os valores.
var quadrados = para (var i = 0; i < 4; i++) { retorna i * i }
var i = 0
var pares = enquanto i < 3 { i++; retorna i * 2 }
escreva(quadrados)
escreva(pares)

Disponível

Funções e parâmetros

Declare funções nomeadas ou anônimas; passe funções como argumentos, retorne funções sem captura e use métodos ligados. Valores padrão são avaliados no chamado e podem usar parâmetros anteriores. ... recebe argumentos variáveis.

linguagem/07_funcoes.delegua

Abrir fonte e contrato de teste 

funcao soma(a: inteiro, b: inteiro = a + 2): inteiro {
    retorna a + b
}
funcao reunir(primeiro, ...resto) { retorna [primeiro, ...resto] }
escreva(soma(3))
escreva(reunir(1, ...[2, 3]))
linguagem/08_funcoes_valores.delegua

Abrir fonte e contrato de teste 

funcao dobro(x) { retorna x * 2 }
var operacao = dobro
funcao criar() {
    // Esta função não captura nenhuma variável de criar().
    retorna funcao(x) { retorna x + 4 }
}
escreva(operacao(3))
escreva(criar()(5))
escreva(mapear([1, 2, 3], funcao(x) { retorna x * 3 }))

Capturas de variáveis externas são bloqueadas. Passe o estado explicitamente por parâmetros; um método ligado mantém apenas seu receptor gerenciado.

Vetores, compreensão e fatias

Vetores são mutáveis. Há índices negativos, espalhamento, compreensão com filtro e fatiamento com passo. Contratos de tipos continuam válidos através de aliases.

linguagem/09_vetores.delegua

Abrir fonte e contrato de teste 

var valores = [3, 1, 2]
valores.ordenar()
escreva(valores, valores.somar())
var removidos = valores.encaixar(1, 1, 7, 8)
escreva(removidos, valores)
linguagem/10_compreensao_fatias.delegua

Abrir fonte e contrato de teste 

var valores = [1, 2, 3, 4, 5]
escreva([x * 3 para cada x em valores se x % 2 == 0])
escreva(valores[::-1], valores[::2])
linguagem/22_contratos_aliases.delegua

Abrir fonte e contrato de teste 

var numeros: inteiro[] = [1]
var alias: qualquer = numeros
tente { alias.adicionar("texto") }
pegue { escreva("bloqueado") }
escreva(numeros)
linguagem/30_metodos_vetor.delegua

Abrir fonte e contrato de teste 

var v = [1, 2]
v.empilhar(3)
escreva(v.concatenar([4]).ordenar(funcao(a, b) { retorna b - a }))
v.adicionar(4)
escreva(v.removerPrimeiro(), v.removerUltimo())
escreva(v.removerUltimo())
escreva(v.removerPrimeiro())
escreva([1, 2, 3].filtrarPor(funcao(x) { retorna x < 3 }).mapear(funcao(x) { retorna x * 3 }))

Métodos: adicionar, empilhar, tamanho, inclui/contem/contém, fatiar, mapear, filtrarPor, remover, removerPrimeiro, removerUltimo, inverter, somar, juntar, concatenar, encaixar e ordenar. Restrições por aliases são monotônicas; modificar durante a iteração não cria snapshot. filtrar global recebe vetor e função; não existe método reduzir neste perfil.

Disponível

Dicionários, tuplas e clonagem

Dicionários associam chaves a valores; tuplas são imutáveis. Desestruture propriedades e use propriedades ordinais de tuplas. clonar copia grafos e preserva ciclos.

linguagem/11_dicionarios.delegua

Abrir fonte e contrato de teste 

var original = {a: 1}
var dados = {...original, b: 2}
const {a, b} = dados
escreva(a, b)
para cada {chave, valor} em {x: 7} { escreva(chave, valor) }
escreva("a" em dados)
linguagem/12_tuplas.delegua

Abrir fonte e contrato de teste 

// Tuplas possuem acesso por índice e por propriedades ordinais.
var tuplaLiteral = [(1, "texto")]
var tipada: (numero, texto) = tupla([2, "outro"])
escreva(tuplaLiteral[0], tuplaLiteral.segundo)
escreva(tipada)
linguagem/20_clonagem.delegua

Abrir fonte e contrato de teste 

var original = {dados: [1]}
var copia = clonar(original)
copia.dados.adicionar(2)
escreva(original.dados, copia.dados)
var ciclo = []
ciclo.adicionar(ciclo)
var clonado = clonar(ciclo)
escreva(clonado[0] == clonado)
linguagem/31_metodos_dicionario.delegua

Abrir fonte e contrato de teste 

var d = {b: 2, a: 1}
escreva(d.chaves().ordenar().juntar("-"), d.valores().ordenar())
escreva(d.contém("a"), d.remover("a"), d.tamanho())

Dicionários: chaves, valores, tamanho, remover e inclui/contem/contém. Tuplas: tamanho, inclui/contem/contém e fatiar, além das propriedades ordinais demonstradas. A iteração de dicionários não garante ordem de inserção.

Texto, Unicode e interpolação

Textos usam UTF-8. Tamanho, índices e fatias contam pontos de código. Interpole expressões com ${...} e use escapes; mudanças de caixa seguem as tabelas Unicode do runtime.

linguagem/13_texto_unicode.delegua

Abrir fonte e contrato de teste 

escreva(tamanho("ação"), "ação"[1], "ação"[1:3])
escreva("  Olá árvore  ".aparar().maiusculo())
var n = 2
escreva("valor ${n + 1}")
linguagem/28_metodos_texto.delegua

Abrir fonte e contrato de teste 

// Busca, divisão, substituição e testes de caixa.
escreva("  a".apararInicio(), "á  ".apararFim())
escreva("a,b".dividir(","), "ação".substituir("ç", "s"))
escreva("ABC".tudoMaiusculo(), "abc".tudoMinusculo())

Métodos: tamanho, inclui/contem/contém, fatiar/subtexto, aparar, apararInicio, apararFim, maiusculo/tudoMaiusculo, minusculo/tudoMinusculo, encontrar, dividir, substituir e concatenar. Pontos de código não equivalem a grafemas visuais.

Com limites

Classes, herança e acessores

Declare campos e métodos; inicialize com construtor, acesse o receptor por isto e a implementação herdada por super. Visibilidades público, privado e protegido usam a classe lexical.

linguagem/14_classes.delegua

Abrir fonte e contrato de teste 

classe Ponto {
    x: numero
    construtor(x: numero) { isto.x = x }
    dobro() { retorna isto.x * 2 }
}
var ponto = Ponto(3)
escreva(ponto.x, ponto.dobro())
ponto.x = 4
escreva(ponto.dobro())
linguagem/15_heranca.delegua

Abrir fonte e contrato de teste 

classe Base {
    protegido { x: numero }
    construtor(x) { isto.x = x }
    valor() { retorna isto.x }
}
classe Filha herda Base {
    construtor(x) { super(x + 1) }
    valor() { retorna super.valor() * 2 }
    dado() { retorna isto.x }
}
var filha = Filha(3)
var metodo = filha.valor  // Receptor explícito, gerenciado pelo GC.
escreva(metodo(), filha.dado())
escreva(filha.eInstanciaDe(Base))
linguagem/16_privacidade_acessores.delegua

Abrir fonte e contrato de teste 

classe Conta {
    privado { _saldo: numero }
    saldo: numero {
        obter() { retorna isto._saldo }
        definir(valor) { isto._saldo = valor * 2 }
    }
    construtor() { isto._saldo = 0 }
}
var conta = Conta()
conta.saldo = 3
escreva(conta.saldo)
linguagem/32_objeto_e_metodos.delegua

Abrir fonte e contrato de teste 

classe Pessoa {
    nome: texto
    construtor(nome) { isto.nome = nome }
    paraTexto() { retorna "Pessoa: ${isto.nome}" }
}
var p = Pessoa("Ada")
escreva(p.tipo())
escreva(p.respondeA("paraTexto"), p.eInstanciaDe(Objeto))
escreva(p)

Classes devem estar no nível do módulo. Campos são declarados; não há injeção arbitrária de campos. Herança por alias dinâmico de classe importada e tipos locais não têm resolução completa.

Disponível

Exceções e limpeza

Use tente, pegue, finalmente e falhar. Excecao possui mensagem; subclasses podem ser tratadas por tipo. Finalmente executa também em retornos e desvios de laços.

linguagem/17_excecoes.delegua

Abrir fonte e contrato de teste 

tente {
    falhar "proposital"
} pegue (erro: Excecao) {
    escreva(erro.mensagem)
} finalmente {
    escreva("limpeza")
}
tente { escreva(1 / 0) } pegue (erro) { escreva(erro) }
linguagem/18_finalmente_retorno.delegua

Abrir fonte e contrato de teste 

funcao obter() {
    tente { retorna 3 } finalmente { escreva("fim") }
}
escreva(obter())
para (var i = 0; i < 2; i++) {
    tente { continua } finalmente { escreva("loop") }
}
linguagem/19_excecoes_tipadas.delegua

Abrir fonte e contrato de teste 

classe MeuErro herda Excecao {}
tente { falhar MeuErro("meu erro") }
pegue (erro: MeuErro) { escreva(erro) }
pegue { escreva("outro erro") }

Falhas do runtime são tratáveis. Sem tratador, o processo termina com status 1. Há localização, mas ainda não uma pilha completa de chamadas Delégua. A localização usa descritores estáticos apenas nas operações falíveis; literais e declarações simples não recebem chamadas de localização. R0001 é o código genérico atual de falha dinâmica.

Disponível

Módulos estáticos

importar recebe caminho literal .delegua, relativo ao módulo que importa. O loader canonicaliza, reutiliza unidades, mostra a cadeia de ciclos e impõe limites de recursos.

modulos/01_importacao.delegua

Abrir fonte e contrato de teste 

var calculos = importar("lib/calculos.delegua")
var outraReferencia = importar("./lib/calculos.delegua")
escreva(calculos.soma(3), outraReferencia.versao, calculos.Valor(4).dado)
compilador/08_otimizacao_modulos.delegua

Abrir fonte e contrato de teste 

// As duas importações compartilham o módulo, sem repetir inicialização.
var primeiro = importar("biblioteca.delegua")
var segundo = importar("biblioteca.delegua")
escreva(primeiro.dobro(2 + 2))

Inicialização é única; se falhar, permite nova tentativa. Exportações não podem ser substituídas. Importação dinâmica, NPM e código estrangeiro são excluídos.

Abrir fonte e contrato de teste

Com limites

Decoradores e asserções

Decoradores registram metadados; decoradores(valor) devolve cópias desses dados. Envelopes de funções livres podem trocar a função, desde que não capturem ambiente. Asserções lançam exceções tratáveis.

linguagem/23_decoradores.delegua

Abrir fonte e contrato de teste 

@minimo(valor=0)
classe Medida { lado: numero }
escreva(decoradores(Medida).classe[0].nome)
funcao alternativa() { retorna 9 }
funcao de decorador trocar(original) { retorna alternativa }
@trocar
funcao obter() { retorna 1 }
escreva(obter())
linguagem/24_assercoes.delegua

Abrir fonte e contrato de teste 

assercao 2 + 2 == 4
escreva("validado")
tente { asserção(falso, "mensagem personalizada") }
pegue (erro) { escreva(erro) }

Envelopes em métodos ainda são rejeitados. Metadados em métodos, classes e campos são suportados. Asserções não são removidas por -o.

Com limites

Otimização e avaliação em compilação

-o habilita passes até ponto fixo. Literais, constantes por identidade, ramos mortos e curto-circuito são simplificados preservando efeitos. //>puro habilita CTFE em uma VM com orçamento.

linguagem/26_ctfe.delegua

Abrir fonte e contrato de teste 

// A VM é usada na compilação, não na execução do binário final.
//>puro
funcao fibonacci(n: inteiro): inteiro {
    se n < 2 { retorna n }
    retorna fibonacci(n - 1) + fibonacci(n - 2)
}
escreva(fibonacci(10))
compilador/01_constantes_escopos.delegua

Abrir fonte e contrato de teste 

// A propagação usa a declaração resolvida, preservando o sombreamento.

se verdadeiro {
    const valor = 9
    escreva(valor + 1)
}
escreva(valor + 1)

compilador/11_ctfe_contrato.delegua

Abrir fonte e contrato de teste 

// A otimização não pode remover a validação de inteiro, nem em funções puras.
//>puro

A VM preserva senão, escopos, parâmetros mutáveis e a ordem dos argumentos, além de validar contratos primitivos de parâmetros, locais e retorno. Código Mensagem / modelo Referência
E0001 %s Diagnóstico legado; consulte a mensagem e a posição.
E0002 Limite de diagnósticos atingido; corrija os erros anteriores. O limite protege contra uma cascata de erros.
E1000 Fim inesperado do arquivo; verifique delimitadores e expressões incompletas. Feche os delimitadores e complete a última expressão.
E1001 %s A mensagem descreve o token ou expressão esperado; o parser tenta recuperar em outro comando.
E1002 Arquivo fonte não contém UTF-8 válido. Salve a fonte como UTF-8.
E1003 Limite de aninhamento sintático excedido. Divida expressões ou blocos profundamente aninhados.
E1004 Limite estrutural da AST excedido; divida a expressão ou o módulo. O frontend limita profundidade e quantidade de nós antes dos passes recursivos.
E2001 Ciclo de importação detectado: %s Quebre a dependência circular mostrada pela cadeia de importação.
E2002 Limite de recursos de carregamento de módulos excedido. Divida o grafo; os limites de tamanho e quantidade são documentados.
E2003 %s Importado por: %s Confira o caminho literal relativo ao módulo que importa.
E3001 O símbolo '%s' não foi declarado. Verifique escopo e grafia; funções não capturam ambientes externos.
E3002 Incompatibilidade de tipo: era esperado '%s' mas foi recebido '%s'. Use um tipo compatível com o contrato declarado.
E3101 Divisão ou módulo por zero demonstrável em compilação. O denominador é uma expressão constante igual a zero.
E3102 Resultado inteiro fora do intervalo de 64 bits. Altere o cálculo ou use valores reais quando apropriado.
E3103 Índice constante inválido: %s. Índices negativos são aceitos dentro dos limites da coleção.
E3104 Incompatibilidade de tipo demonstrável: esperado '%s', recebido '%s'. Contratos explícitos não são removidos pela otimização.
E3105 Operação demonstravelmente inválida: %s. Use os tipos e limites aceitos pelo runtime.
E3106 Conversão literal inválida para '%s'. Valide o texto de entrada ou trate dados recebidos em execução.
E3107 Deslocamento constante fora do intervalo [0, 63]. A quantidade de bits precisa estar dentro dos limites de 64 bits.

R0001 %s Falha dinâmica do runtime; consulte a operação e a localização informadas. Tipos dinâmicos, aliases e entrada externa continuam validados em execução.
W0001 %s Aviso legado; consulte a mensagem e a posição.
W3001 Código inalcançável após transferência de controle. Remova ou reorganize a cauda que não executa.
W3002 Função com retorno tipado pode terminar sem retornar valor; o retorno implícito é nulo. Garanta um retorno nos caminhos relevantes.
W4001 Captura externa de '%s' detectada: exigiria upvalues, recurso desabilitado por segurança. Passe estado por parâmetros ou receptor explícito.
W4002 Carregamento dinâmico/NPM/FFI não é suportado por segurança. Use fontes .delegua conhecidas na compilação.

O parser recupera erros independentes. A verificação estática antecipa divisão por zero, overflow, índices e contratos literais. Em regiões com pegue, falhas conhecidas geram avisos W31xx e continuam tratáveis. Dados dinâmicos, aliases e retornos de funções ainda exigem validação em execução. Diagnósticos legados usam E0001/W0001/H0001; LSP e fix-its não existem.

Excluído por segurança

Exclusões de segurança

Upvalues/capturas de estado externo, FFI arbitrária, ponteiros crus, eval, carregamento dinâmico e NPM não são expostos. Esses exemplos devem falhar e fazem parte dos testes.

seguranca/01_captura_local.delegua

Abrir fonte e contrato de teste 

funcao criar(x) {
    retorna funcao() { retorna x } // Captura implícita proibida.
}
seguranca/02_captura_global.delegua

Abrir fonte e contrato de teste 

var externo = 1
funcao obter() { retorna externo }
seguranca/03_ffi.delegua

Abrir fonte e contrato de teste 

// Código nativo arbitrário não faz parte do perfil compilado.
classe estrangeira Biblioteca {}
seguranca/04_importacao_dinamica.delegua

Abrir fonte e contrato de teste 

var caminho = "modulo.delegua"
var modulo = importar(caminho)

Uma função que retorna outra função sem captura é válida. Receptor explícito de método ligado é suportado. Ausência de implementação não é motivo para chamar um recurso de inseguro.

Com limites

Plataformas e limites da implementação

Linux x86_64 é a plataforma validada com DMD e LDC2, Clang e GCC. A CLI permite configurar target, sysroot, compilador e runtime separadamente para preparar builds cruzados.

Windows/macOS e executáveis cruzados ainda não foram validados. Instaladores são shell/Linux. Não há bigint, dialetos extras, threads da linguagem, debugger ou bibliotecas Node. Consulte o guia de desenvolvimento para configurar a toolchain.
