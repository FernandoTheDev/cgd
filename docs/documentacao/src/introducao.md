# Introdução

O **CGD (Compilador Geral Delégua)** é um compilador desenvolvido para a linguagem de programação [Delégua](https://github.com/DesignLiquido/delegua). O projeto nasceu da necessidade de expandir o potencial da linguagem, que anteriormente tinha foco exclusivo na educação, transformando-a em uma ferramenta robusta e adequada para uso profissional no mercado.

Esta evolução mantém a característica original da Delégua de ser acessível para iniciantes em programação, mas agora oferece um caminho de crescimento contínuo, permitindo que desenvolvedores permaneçam na linguagem conforme avançam em suas carreiras.

## Sobre o Projeto

O CGD é desenvolvido inteiramente em [D](https://dlang.org), aproveitando sua performance e expressividade. Para o backend, utilizamos:

- **[LLVM](https://llvm.org)** - Infraestrutura de compilação e otimização
- **[Clang](https://clang.org)** - Geração de código nativo

## Recursos Avançados

O compilador oferece funcionalidades significativamente expandidas em relação ao interpretador original:

### Novos Recursos de Sistema

- **Ponteiros** para manipulação direta de memória
- **Templates** para programação genérica
- **Gerenciamento manual de memória** com alocação e desalocação explícitas
- **Tipos primitivos adicionais** para maior precisão e controle

### Melhorias na Linguagem

- **Classes aprimoradas** com recursos mais poderosos
- **Compatibilidade completa** com todas as funcionalidades do interpretador oficial
- **Implementação otimizada** de recursos existentes
- **Recursos de baixo nível** para desenvolvimento de sistemas
